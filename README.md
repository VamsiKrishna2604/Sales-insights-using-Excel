# Sales insights using Excel
This project takes historical sales performance data of a global retail store and presents key business insights.This is done with the help of visualization and a dashboard.

## Dataset overview
Key fields:
* Orders: Order Date,Ship Date,Ship Mode
* Customers: Customer ID,Customer Name,Segment,Country,City,State,Postal Code,Region
* Products: Product ID,Category,Sub-Category,Product Name,Sales

## Tools & Techniques Used
* Microsoft Excel
* Pivot Tables & Pivot Charts
* Slicers
* Lookup

## Key Insights:

* There is regon wide disparity and the "West" region has the highest number of sales but the "Central" region has the highest sales amount

* Category wise,the trend of sales is highly fluctuating,but "Furniture"category is constantly underperforming

* The top products mostly comprise of items related to printing and binding
